Why ParSolGen?

Describe the algorithm once. ParSolGen handles the parallelization: distribution across nodes, communication, load balancing and accelerator offload.

01

Automated distributed memory support

ParSolGen automatically generates a highly efficient parallel program from the given numerical algorithm description. It automatically handles communication between the nodes of a supercomputer, distributes and balances the load. No manual MPI programming required.

02

Automated GPU support

ParSolGen is designed for modern heterogeneous HPC systems combining both CPUs and GPUs. Goopax allows the automated offload of the work to various GPU-based accelerators. ParSolGen automatically handles the load distribution and data transfer between the host and GPUs.

03

No more complicated network programming

Communication between the nodes of a supercomputer and between the installed accelerators is handled automatically. No MPI knowledge is required. Generate parallel programs with ParSolGen and compile them with any mpicxx compiler.

04

Complex information dependencies handling

ParSolGen supports various numerical algorithm domains, including dense and sparse linear algebra and stencil computations, while keeping the generated programs fast.

Products

Two ways to build the same parallel program: write it in the ParSolGen algorithm language, or write it in Python with PySol.

ParSolGen

Parallel Solvers Generator: compiler and runtime

ParSolGen is an automated parallel program generator. You describe the algorithm in a compact C-like language (.sol) over blocked, versioned arrays, and implement the per-block computations as ordinary C++ functions. The sgc compiler builds a parallel MPI program from them, and the PSRts runtime library schedules the work.

  • Distributed blocked arrays with automatic data placement
  • Dependency analysis from array versions: no explicit synchronization
  • CPU clusters and CPU+GPU nodes (via Goopax)
  • Dense and sparse linear algebra (LLT, CSR SpMV, BiCG) and stencils
ParSolGen docs Examples on GitHub

PySol

Python front-end for ParSolGen

PySol lets you write a ParSolGen algorithm as a decorated Python function. The @pysol decorator analyses the function, generates the .sol description, and pysol_compile / pysol_run build and run it as a shared library from the same script.

  • Plain Python syntax: typed variables, for … in range, while, if
  • Array, GrowingArray, CSRMatrix and user structs
  • One-line halo exchange with pysol_update_array
  • Vector operators (+, *, @) and sum / min / max reductions

ParSolGen + PySol in one Docker container

Want to play with ParSolGen and PySol before setting them up on a cluster? Our ready-made Docker sandbox builds the whole toolchain for you, so you can write, compile and run parallel programs on a single machine right away. The only thing you need installed is Docker.

  • ParSolGen v0.5-alpha (CPU release) and PySol, ready to use
  • GCC 15.2.0, Python 3.10.12, MPICH 5.0.0, Boost 1.90.0 and GKlib preinstalled
  • A config.json already in place for every PySol example
  • Tested while it builds: the image is only created if the PySol example tests pass
Download Dockerfile pysol-config.json

Intended for single-node experiments. The first build compiles GCC from source and takes a while; the resulting image is about 1.3 GB. For clusters and GPUs use the release archives.

  1. Get the two files

    mkdir parsolgen-sandbox && cd parsolgen-sandbox
URL=https://parsolgen.github.io/docker
curl -fsSLO $URL/Dockerfile
curl -fsSLO $URL/pysol-config.json

  2. Build the image

    docker build -t parsolgen:0.5-alpha .
# more parallel make jobs: --build-arg JOBS=16

  3. Start it and play

    docker run --rm -it parsolgen:0.5-alpha
# inside the container (/opt/pysol/examples/simple):
python3 run_tests.py      # All 6/6 test(s) passed
ls ../                    # more examples to explore
